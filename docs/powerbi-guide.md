# Power BI Dashboard Guide

The dashboard is saved as a **Power BI Project (PBIP)**: a text-based format that Git can track. The semantic model is in TMDL and the report is in PBIR.

```
powerbi/
├── Bellabeat.pbip                 # open this file in Power BI Desktop
├── Bellabeat.SemanticModel/       # tables, Power Query, relationships, DAX measures
├── Bellabeat.Report/              # report page, visuals, theme
└── theme/BellabeatMinimal.json    # same theme as a standalone file
```

## Open the dashboard

1. Install a recent **Power BI Desktop** (Windows).
2. If your version asks for it, enable these preview features under
   *File › Options and settings › Options › Preview features*, then restart:
   - Power BI Project (.pbip) save option
   - Store semantic model using TMDL format
   - Store reports using enhanced metadata format (PBIR)
3. Clone or download this repository, then open `powerbi/Bellabeat.pbip`.
4. Point the model at the data folder:
   *Transform data › Edit parameters › `DataFolder`* → full path to this repo's `data\` folder, ending with a backslash
   (default: `C:\Bellabeat-Smart-Device-Analysis\data\`).
5. Click **Refresh**. The page should match `images/dashboard_powerbi_preview.png`.
6. Optional: *File › Save as* `.pbix` to publish to Power BI Service, and replace the preview image with a real screenshot.

## Data model

| Table | Source | Grain | Notes |
|---|---|---|---|
| `DailyActivity` | `data/dailyActivity_merged.csv` | one row per user per day | adds `Weekday`, `Step Band` in Power Query |
| `Users` | grouped from `DailyActivity` | one row per user | `User Avg Steps`, `Segment` |
| `Intensity` | static | 4 rows | disconnected helper for the minutes-by-intensity chart |
| `Measures` | none | none | holds all DAX measures |

Relationship: `DailyActivity[Id]` (many) → `Users[Id]` (one), single direction.

**Segments** (average daily steps per user): Sedentary < 5,000 · Lightly Active 5,000–7,499 · Fairly Active 7,500–9,999 · Very Active ≥ 10,000.

## DAX measures

```DAX
Total Users              = DISTINCTCOUNT ( DailyActivity[Id] )
Days Tracked             = COUNTROWS ( DailyActivity )
Avg Daily Steps          = AVERAGE ( DailyActivity[TotalSteps] )
Avg Daily Calories       = AVERAGE ( DailyActivity[Calories] )
Sedentary Hours / Day    = DIVIDE ( AVERAGE ( DailyActivity[SedentaryMinutes] ), 60 )
Active Minutes / Day     = AVERAGE ( DailyActivity[VeryActiveMinutes] ) + AVERAGE ( DailyActivity[FairlyActiveMinutes] )
% Days 10k+ Steps        = DIVIDE ( CALCULATE ( [Days Tracked], DailyActivity[TotalSteps] >= 10000 ), [Days Tracked] )
% Days Not Worn          = DIVIDE ( CALCULATE ( [Days Tracked], DailyActivity[TotalSteps] = 0 ), [Days Tracked] )
% of Users               = DIVIDE ( [Total Users], CALCULATE ( [Total Users], REMOVEFILTERS ( Users[Segment] ) ) )
% of Days                = DIVIDE ( [Days Tracked], CALCULATE ( [Days Tracked], REMOVEFILTERS ( DailyActivity[Step Band] ) ) )
Avg Minutes by Intensity =
    SWITCH (
        SELECTEDVALUE ( Intensity[Intensity] ),
        "Very Active",    AVERAGE ( DailyActivity[VeryActiveMinutes] ),
        "Fairly Active",  AVERAGE ( DailyActivity[FairlyActiveMinutes] ),
        "Lightly Active", AVERAGE ( DailyActivity[LightlyActiveMinutes] ),
        "Sedentary",      AVERAGE ( DailyActivity[SedentaryMinutes] )
    )
```

## If the project does not open

PBIP files are generated by hand here, so a Desktop version mismatch can occasionally block opening. In that case build it manually in a new report (about 20 minutes):

1. *Get data › Text/CSV* → `dailyActivity_merged.csv`. In Power Query, set `Id` to Text and `ActivityDate` to Date (locale English (US)).
2. Copy the Power Query steps from `Bellabeat.SemanticModel/definition/tables/*.tmdl` (the `source =` block of each partition) into blank queries named `DailyActivity`, `Users`, `Intensity`.
3. Create the relationship and the measures above, and set *Sort by column* for `Weekday Short`, `Step Band`, `Segment`, `Intensity`.
4. *View › Themes › Browse for themes* → `powerbi/theme/BellabeatMinimal.json`.
5. Place the visuals following the layout table.
